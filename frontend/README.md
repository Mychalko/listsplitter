# ESP List Processing - Frontend

Next.js frontend for ESP list processing application.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create environment file:
```bash
cp .env.local.example .env.local
```

3. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

### Part 1: ESP Column Identification
- File upload with drag-and-drop support
- Automatic ESP column detection
- Column selection interface for ambiguous cases
- Data preview for user verification

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Axios for API calls
